# 电池接口日志分析

## 项目简介
这是对 MobaXterm 日志文件的分析项目，用于可视化和分析电池接口的性能数据。

## 文件说明

- **battery_analysis.py** - Python 分析脚本
- **battery_analysis_chart.png** - 生成的分析图表
- **201-018_10mm_Normal_DigitalRhythm.log** - 原始日志文件

## 图表说明

这个双坐标轴图表展示了两个关键指标：

### 主轴（左侧，蓝色）
- **指标名称**：电池百分比
- **数据范围**：89% - 90%
- **描述**：实时电池电量百分比

### 次轴（右侧，橙色）
- **指标名称**：功率/能量值
- **数据范围**：8084 - 27858 mW
- **描述**：电池功率或能量消耗值

### 时间范围
- **开始时间**：2026-05-28 10:14:43
- **结束时间**：2026-05-28 10:15:27
- **总数据点**：92 个

## 数据分析

1. **稳定期**（10:14:43 - 10:14:50）
   - 电池百分比保持在 90%
   - 功率值相对稳定（7979-8086 mW）

2. **波动期**（10:14:50 - 10:15:24）
   - 电池百分比下降到 89%
   - 功率值明显上升（8625-27858 mW）
   - 存在高负载应用运行

3. **恢复期**（10:15:24 - 10:15:27）
   - 功率值快速下降到低水平（8141-8264 mW）
   - 电池百分比保持在 89%
   - 系统恢复正常运行
